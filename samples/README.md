# Samples

One representative output per pipeline, generated from the sample inputs in this repo.

- `sample-report.docx`: docs-forge output from `docs-forge/samples/sample-report.md`, a formatted engineering report with cover page, numbered headings, table and figure placeholder.
- `sample-report.pdf`: PDF render of `sample-report.docx`.
- `deck-template.pdf`: design-studio deck template rendered to a 16:9 PDF by `build-pdf.sh`.
- `drive-unit-audit.docx`: cad-audit output from `cad-audit/samples/drive-unit.step`, fed through docs-forge into a finished audit report.
- `drive-unit-audit.pdf`: PDF render of `drive-unit-audit.docx`.
